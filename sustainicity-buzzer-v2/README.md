# Sustainicity Round 1 — Live Buzzer

Multiplayer Socket.IO buzzer for an OC/host and teams using their own phones.

## Run
1. Install Node.js.
2. In this folder run `npm install`.
3. Run `npm start`.
4. Open the displayed local URL on the host laptop.
5. For phones on the same Wi-Fi, use the host computer's local IP + port.

For an actual campus event, deploy this Node app to a public Node-compatible host so teams can join from mobile data/Wi-Fi.
